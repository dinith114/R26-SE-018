# models/

Empty until you train. Everything here is generated by `src/train.py` and
`src/evaluate.py`, so nothing in this folder is hand-written.

| File | Written by | What it is |
|---|---|---|
| `disease_model.keras` | train.py | The trained classifier |
| `disease_model.weights.h5` | train.py | Weights-only fallback if the `.keras` file will not load on a different TensorFlow version |
| `class_names.json` | train.py | Class order. **Inference is wrong without it** — index 0 is the alphabetically first folder, not a fixed disease |
| `training_metadata.json` | train.py | Counts, class weights, arguments, TF version, best scores |
| `training_history.json` | train.py | Per-epoch loss and accuracy, for the training-curve figure |
| `metrics_test.json` | evaluate.py | Per-class precision / recall / F1, confusion matrix, threshold sweep |
| `evaluation_report_test.txt` | evaluate.py | The same, as readable text for the report |
| `confusion_matrix_test.png` | evaluate.py | Confusion matrix figure |

Both scripts were verified end to end on 29 Aug 2026 with TensorFlow 2.21.0.
That verification run was a `--smoke-test` (one epoch on three batches) and its
outputs were **deleted on purpose** — a model trained for one epoch scores
around 0.47 macro-F1, and those numbers must never be mistaken for results.

To produce real files:

```bash
cd src
../.venv/Scripts/python.exe train.py        # or on Colab -- see HOW_TO_RUN.md
../.venv/Scripts/python.exe evaluate.py
```
