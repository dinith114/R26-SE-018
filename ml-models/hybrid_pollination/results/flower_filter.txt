FLOWER FILTER - stage 2 of the input gate (orchid vs other flower)
==========================================================================

[1] Positives - this project's own orchid photographs
  1190 images, 375 groups

[2] Negatives - Oxford Flowers-102
  8089 other-flower images across 100 species
  100 images held out from the two ORCHID classes (2, 7) - excluded from
  training so the filter is never taught to call an orchid 'not orchid'

[2b] Negatives - non-orchid plants (foliage, not flowers)
  80 photographs of ferns, palms, aloes, bromeliads, cacti
  collected with search terms DIFFERENT from the held-out ferns and
  houseplants in gate_validation, so the test set stays honest
  total negatives: 8169

[3] Fitting
  logistic regression, balanced class weights
  threshold 0.1854 (keeps 99% of the project's own photographs)

[4] In-domain check (same sources as training - optimistic by design)
  project photos called orchid   : 99.0%
  Flowers-102 called other flower: 87.9%
  NOTE: both sets were seen in training. The number that counts is below.

[5] THE HONEST TEST - Wikimedia Commons only, neither training source

  set                       n  called orchid   median p
  ------------------------------------------------------

  Wikimedia roses/tulips   45           27%       0.07

  ROC AUC on the third source: 0.857
  (0.5 would mean the filter had only learned which camera took the photo)
